# Netflix Analytics Project

## Overview
This project analyzes Netflix Movies and TV Shows data using Python, SQL, Pandas, SQLite, and Matplotlib in Google Colab.

The project focuses on extracting insights from Netflix content such as:
- Movies vs TV Shows distribution
- Rating analysis
- Country-wise content production
- Release year trends
- Duration analysis
- Director and content analysis

---
